# 🚀 Synthora AI

Synthora AI is an AI-powered content generation platform that helps users create blogs, YouTube descriptions, viral titles, and other AI-generated content through a simple and intuitive interface.

## 🌐 Live Demo

**Frontend:** https://synthora-ai-7db7.vercel.app/

## ✨ Features

* 🔐 Secure Login & Signup (JWT Authentication)
* 🤖 AI Content Generation
* 📝 Blog Generator
* 🎥 YouTube Description Generator
* 🔥 Viral Title Generator
* 📱 Responsive UI

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript, HTML, CSS
* **Backend:** Spring Boot, Spring Security, JWT
* **Database:** PostgreSQL
* **Deployment:** Vercel, Render

## 🚀 Run Locally

```bash
git clone https://github.com/Saijal07/Synthora-AI.git
cd Synthora-AI
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
mvn spring-boot:run
```
